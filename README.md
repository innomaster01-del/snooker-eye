# Snooker Eye 🎱

אפליקציית אנדרואיד שמכוונים בה את המצלמה על שולחן סנוקר. היא מזהה את השולחן ואת הכדורים, ומציירת על התמונה קווים מדויקים בסגנון שידורי טלוויזיה: לאן לכוון את הלבן, כדור רפאים, לאן ילך כדור המטרה, ואיפה ייעצר הלבן.

## הורדה
את קובץ ה-APK האחרון מורידים מ-**Releases**. פותחים אותו בטלפון ומאשרים "התקנה ממקור לא ידוע".

## שלושת המצבים
| מצב | מה קורה |
|---|---|
| 📷 צילום | מצלמים פעם אחת, נוגעים בכדור ומקבלים את המכות. אפשר לתקן פינות וכדורים ידנית |
| 📐 חצובה | הטלפון על מעמד, נועלים את השולחן, והקווים מתעדכנים לייב |
| ✋ ביד | השולחן מזוהה בכל פריים, והקווים נשארים צמודים לבד |

🎮 **דמו**: שולחן סינתטי לניסיון בלי שולחן אמיתי.

## זיהוי
- זיהוי השולחן בכל פריים, ודחיית מסגרות שבהן השולחן חתוך או קופץ
- כדורים מזוהים בחיתוך ברזולוציה גבוהה סביב השולחן, לפי מודל צבע של הבד (צללים לא נחשבים כדור)
- כדורים צמודים מופרדים בהתאמת עיגולים
- כדור מוצג רק אחרי שזוהה בכמה פריימים, והסימונים עומדים במקום
- **נגיעה בכדור שלא סומן** → האפליקציה מחפשת אותו בתמונה ומסמנת. לחיצה ארוכה = שינוי צבע/מחיקה

## מה מחושב
- מכה ישירה, דאבל (כדור מטרה דרך גומי), לבן דרך גומי אחד או שניים, ושרשרת של שני כדורים
- זווית חיתוך ועובי פגיעה (מלא, ¾, ½, ¼, דק)
- מסלול הלבן אחרי הפגיעה, עם עליון, סטופ ואחורי וכוח 1 עד 5, כולל גומיות ואזהרת פאול
- סיכוי הצלחה לפי רמת השחקן, ועמדה לכדור הבא לפי חוקי "כדור על"

## איך זה בנוי
- `app/src/main/assets/www`: כל האפליקציה (JavaScript בלי ספריות חיצוניות)
  - `vision.js`: זיהוי הבד, ארבע הפינות, homography, הערכת תנוחת המצלמה, וזיהוי כדורים וסיווג הצבעים
  - `shots.js`: גיאומטריה ופיזיקה (כדור רפאים, שיקוף גומיות, החלקה וגלגול של הלבן)
  - `render.js`: גרפיקה על השולחן ומפה עליונה
- `MainActivity.java`: מעטפת WebView שמגישה את הקבצים מתוך ה-APK ומאשרת גישה למצלמה
- `.github/workflows/android.yml`: בונה APK חתום ומפרסם אותו ב-Release בכל push

## בדיקה מקומית
```
node tools/test.mjs   # מריץ את האפליקציה על שולחן הדמו ובודק את דיוק הזיהוי
```
